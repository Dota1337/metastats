# Game-Icons

`lol-icon.png` und `tft-icon.svg` sind offizielle Riot-Icons, lokal gespiegelt
aus den League-Client-Assets (ursprünglich aus CommunityDragons Plugins
`rcp-fe-lol-static-assets` und `rcp-fe-lol-tft`).

Sie liegen hier in `/public`, damit die Anzeige nicht von der Verfügbarkeit des
CommunityDragon-Servers abhängt.

Verwendet von `app/components/GameStrip.tsx`.
